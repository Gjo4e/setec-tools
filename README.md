# Setec Залиха

Неофицијална Android апликација со камера-скенер.

Копчето **📷 Скенирај** ја отвора камерата. ML Kit OCR го чита текстот од фотографијата, ја извлекува шифрата до „Шифра:“ (пример **12959**) и овозможува проверка или рачна исправка. Потоа апликацијата се обидува да го пребара производот на официјалниот Setec.mk.

Пребарувањето зависи од јавниот сајт и може да бара рачно избирање на производот. Достапност по салони се проверува преку оригиналниот сајт; не се прикажува непотврдена залиха.

## Android APK
Отвори Actions → Build Setec Zaliha APK → Run workflow (или види го автоматскиот build по push).
По успешен build преземи го артефактот Setec-Zaliha-APK, отпакувај и инсталирај app-debug.apk.

Се користат JDK 17, Gradle 8.9, Android SDK 35 и Google ML Kit.
Апликацијата користи посебен Android package ID за да не се судира со старите пробни APK верзии.
